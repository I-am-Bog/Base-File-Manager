# Base-File-Manager

# Цель работы
Основной целью работы является развитие умений и навыков в создании комплексных программных проектов, а также в освоении программного взаимодействия с файловой системой на языке Python.

# Задания для выполнения
Студентам необходимо разработать базовую версию файлового менеджера. Этот программный проект должен позволять пользователю взаимодействовать с файлами и папками в заданной рабочей директории. Список требуемых функций включает:

Создание и удаление директорий.

Навигация по файловой системе внутри рабочей директории.

Создание, чтение, запись, удаление, копирование, перемещение и переименование файлов.

Пользовательский интерфейс должен быть текстовым и работать по принципу командной строки.

# Указания к выполнению
Настройка рабочей директории: Укажите путь к рабочей папке в конфигурационном файле проекта. Этот файл должен быть отдельным от основного кода.

Структура проекта: Код должен быть структурирован и разделен на модули или классы, каждый из которых отвечает за определенную функцию файлового менеджера.

Использование Git: Разработка должна проходить с использованием системы контроля версий Git, а результаты должны быть опубликованы в репозитории на GitHub.

Дизайн команд: Перед началом разработки необходимо тщательно спланировать набор и структуру команд, которые будут доступны пользователю. Стремитесь к оригинальности и избегайте копирования интерфейса существующих оболочек.

# Отчёт о реализации проекта

## Структура проекта

Проект организован по модульному принципу и состоит из четырёх файлов:

```
base-file-manager/
├── main.py          # Точка входа, главный цикл приложения
├── file_manager.py  # Класс FileManager - ядро файлового менеджера
├── commands.py      # Класс CommandHandler - обработчик команд
└── config.py        # Конфигурационный файл
```

## Описание модулей

### 1. config.py — Конфигурация

Конфигурационный файл отделён от основного кода в соответствии с требованиями. Содержит словарь `CONFIG` с настройками:

| Параметр | Значение | Описание |
|----------|----------|----------|
| `working_directory` | `"./workspace"` | Путь к рабочей директории |
| `allowed_extensions` | `[.txt, .py, .json, ...]` | Разрешённые расширения файлов |
| `max_file_size_mb` | `10` | Максимальный размер файла для чтения |
| `show_hidden_files` | `False` | Показ скрытых файлов |
| `encoding` | `"utf-8"` | Кодировка для работы с файлами |

### 2. file_manager.py — Ядро файлового менеджера

Класс `FileManager` реализует все основные операции с файловой системой:

**Изоляция рабочей директории:**
- Метод `_is_safe_path()` проверяет, что путь находится внутри рабочей директории
- Предотвращает выход пользователя за пределы изолированного пространства

**Кроссплатформенность:**
- Использование `pathlib.Path` вместо строковых путей обеспечивает совместимость с Windows и UNIX
- Метод `_resolve_path()` корректно обрабатывает относительные и абсолютные пути

**Реализованные методы:**

| Метод | Описание |
|-------|----------|
| `create_directory()` | Создание директорий (с поддержкой вложенных) |
| `delete_directory()` | Удаление директорий (с флагом `-f` для непустых) |
| `change_directory()` | Навигация (`cd ..`, `cd /`, `cd <dir>`) |
| `list_directory()` | Вывод содержимого с метаданными |
| `create_file()` | Создание файлов |
| `read_file()` | Чтение с проверкой размера |
| `write_file()` | Запись/дозапись в файл |
| `delete_file()` | Удаление файлов |
| `copy_file()` | Копирование файлов и директорий |
| `move_file()` | Перемещение файлов и директорий |
| `rename_file()` | Переименование |
| `get_file_info()` | Получение метаданных |

### 3. commands.py — Обработчик команд

Класс `CommandHandler` реализует паттерн команд и предоставляет текстовый интерфейс

**Дизайн команд:**
- Поддержка однотипных команд (например, `ls`/`dir`, `exit`/`quit`/`q`)
- Форматированный вывод с псевдографикой (разделители, таблицы)

### 4. main.py — Точка входа

Содержит функцию `main()` с главным циклом приложения:
Обрабатывает исключения `KeyboardInterrupt` и `EOFError` для корректного завершения работы.

## Архитектурные решения

1. **Разделение ответственности:** Каждый модуль отвечает за свою область:
   - `file_manager` — логика работы с файлами
   - `commands` — выполнение команд
   - `main.py` — пользовательский интерфейс
   - `config.py` — конфигурация
2. **Возврат значений:** Все методы возвращают кортеж `(success: bool, message: str)` для единообразной обработки результатов.
3. **Обработка ошибок:** Все операции обёрнуты в `try-except` блоки с информативными сообщениями об ошибках.
4. **Типизация:** Использованы type hints (`Tuple`, `List`, `Dict`, `Optional`) для улучшения читаемости кода.
